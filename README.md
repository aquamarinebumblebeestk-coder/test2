# svsup

iPhone の Safari で動く画像管理アプリ(PWA)です。ホーム画面に追加すると通常のアプリのように全画面で起動し、オフラインでも使えます。

## 機能

- **登録**: クラス(エルフ / ロイヤル / ウィッチ / ドラゴン / ナイトメア / ビショップ / ネメシス)を選んで、画像を1件ずつ追加(各クラス最大5件)。登録済み画像は ✕ ボタンで削除できます。
- **表示**: クラスを選ぶと登録済み画像が一覧表示され、タップで拡大表示。拡大中はピンチで拡大、左右スワイプ・‹ › ボタンで前後の画像に移動、上下スワイプで閉じます。
- 小窓表示機能はコード内に残してありますが、現在は非表示です(`app.js` の `MINI_ENABLED` を `true` にすると有効)。
- **バックアップ**: 全画像を1つのファイルに保存(共有シートから「"ファイル"に保存」)、そのファイルから復元できます。

画像は端末内(IndexedDB)にのみ保存され、外部には送信されません。

## アップデートについて

アプリを更新しても登録画像は消えません。**ホーム画面のアイコンを削除して入れ直す必要はありません**(削除すると画像も消えます)。
新しいバージョンを公開すると、次に開いたときに自動で最新版になり、開きっぱなしの場合は「新しいバージョンがあります」が表示されます。

更新を公開するときは `version.json` のバージョン番号を上げてください。

## iPhone へのインストール

1. GitHub のリポジトリ設定 **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `master` / `(root)` にして保存
2. 数分後に表示される URL(`https://<ユーザー名>.github.io/<リポジトリ名>/`)を iPhone の Safari で開く
3. 共有ボタン → **「ホーム画面に追加」**

※ ホーム画面のアイコンを削除した場合や機種変更時に備えて、ときどき「バックアップ」タブから保存しておくと安心です。
